# Resume and Interview Notes: CareGuardian Connect — Synthetic Adherence Analytics

> Only use these bullets **after downloading, running, reviewing, and
> understanding the code**. These are **independent portfolio projects**,
> distinct from the organizations on the current resume. All numerical
> examples refer to synthetic test fixtures, not real-world impact.

## Potential portfolio bullets (edit to reflect your actual work)

- Developed a reproducible Python analytics pipeline for 576 **synthetic** medication events, combining data-quality validation, descriptive summaries and a participant-group-held-out logistic-regression baseline.
- Built structured model-evaluation outputs (confusion matrix, accuracy, precision and recall), toy reminder-text review checks, and hypothetical EOQ/NPV calculators.
- Added unit and integration tests and generated machine-readable JSON plus a Markdown technical report.

**Interview explanation:** "The academic medication-management concept on my existing resume motivated an independent coding prototype. My new repository uses fake participant records and demonstrates validation, modeling, financial calculations and testing. It is not a clinical product or a copy of the academic team's code."

**Be ready to explain:** target leakage; why participants must be split by ID; logistic regression baseline; confounding; tradeoffs between precision/recall; EOQ and discounting assumptions; limitations of keyword safety checks.

**Never claim:** clinical accuracy, actual patient outcomes, deployment at Johnson & Johnson, a real medication dispensing device, or that this repository was the original 2026 course-team deliverable.

## What matters before putting this on a resume

1. Run the commands from the README on your own computer.
2. Open and read the central `.py` and `.sql` files.
3. Check one output file against the relevant source CSV.
4. Make at least one meaningful modification that you can explain.
5. Rerun tests and commit your changes.
6. Be transparent that the implementation is new and independently developed
   with AI assistance if asked about development history.

The code is supplied as a starting deliverable for learning and portfolio
building. Owning the repository does not by itself establish personal
engineering experience or employer use.
